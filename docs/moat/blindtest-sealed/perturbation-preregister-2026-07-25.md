# 扰动包预注册件(ADJ-0725-07①d·commit-reveal·2026-07-25封存)

> **禁读**:本目录对评审席、机制路径审计席、扰动包评审席**全部禁读**;仅CGM与GM(开封时)可见。违反=该轮扰动测试作废。
> **效力**:改写幅度与预期方向之设定属**判断类**,依ADJ-0725-06通则标**「临时生效·候Fable 5复裁」**。
> **原理**:测**灵敏度而非水平**——评审席即使识别标的,亦无从知晓哪些变量被改写、改了多少、朝哪个方向,故识别不影响结论有效性。

## 一、通用改写规则(机械·三包同构)

1. **只改机制变量,不改身份变量**:分部结构/业务性质/监管事实/组织沿革**一律不动**(动之即改变标的身份,污染对照);
2. **改写点=各包最能承重的护城河证据**(即评审席最可能据以给高档位者),每包 **4 项**;
3. **改写幅度=劣化至"该机制明显受损但未崩塌"档**(避免改成极端值使判定变得trivial);
4. **数值改写须内部自洽**(如留存下降须同步反映在经常性收入增速上,否则评审席可由不自洽识破扰动);
5. 改写后包与原包**其余部分逐字相同**;
6. 扰动包与原包**分别交不同评审席**(同席先后跑会记忆污染)。

## 三、开封与判读程序

1. 评审席对**原包**与**扰动包**分别出档(不同席·互不可见·均须开卷自报识别状态);
2. CGM开封本件,计算**档位位移** = 原包档位 − 扰动包档位;
3. **判据**:
   - 位移方向正确 ∧ 幅度落在预期区间 → **尺子有灵敏度**✓;
   - 位移为0或反向 → **尺子钝或叙事驱动**,该尺相关条款回炉;
   - 位移方向正确但幅度显著小于预期 → 灵敏度不足,记入案例窗待修订;
   - 位移幅度显著大于预期 → 过度敏感(噪声放大),同样记入案例窗;
4. 判读结论入试运行报告,与机制路径审计结果**交叉读**(两控制指向同一诊断则结论强)。
