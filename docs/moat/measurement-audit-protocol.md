## §一 路线定性(承继v2)

大盘平台域**不追求真盲**——经营数据本身即指纹,加码遮蔽只削弱证据而识别照旧(v1实测)。**盲性功能由控制设计承担,不由匿名化承担。**

## §二 材料处理(承继v2·零伤料)

保留一次遮蔽:去公司名/品牌名/产品名、去价格语境、**去我方既有结论**(防锚定之真正对象)、绝对金额比率化(非伤料)。
**禁用栏**(v1伤料条款·削弱证据而不增盲性):时点相对化/量级降精度/辖区去名/事件日期相对化/结构指纹弱化。**例外**:未来若出现真能实现盲性之域,经GM裁可局部启用。
**保真底线五条(硬约束·违一即材料不合格)**:①读数方向与幅度;②**时序次序与绝对时点**;③机制描述;④口径标注与置信等级;⑤缺口与冲突清单。

## §三 控制设计(v2四件 + 段C三件补入 = 七件)

### 承继v2四件

**(1) 接受识别性(明记)**:材料头部载明"本材料未实现盲性,评审席可能识别标的",不做虚假保障。
**(2) 开卷自报——测量装置非控制手段**:评审席须自报是否已识别标的、依据、识别发生在哪一节后;**单独不足以替代盲性**,仅供事后校准。
**(3) 机制路径审计(对识别免疫)**:独立席仅凭证据包重推各轴读数,与评审席逐轴对表;**档位一致 ∧ 机制路径不成立 → 判"叙事驱动非尺子驱动",该轮读数作废重跑**。
**(4) 机制干预对(原"扰动包")**:机械改写关键机制变量造劣化包,**测灵敏度而非水平**;预注册件=`blindtest-sealed/perturbation-preregister-2026-07-25.md`(逐包12项改写+预期方向+四判据)。

### 段C补入三件(ADJ-0725-08①·我方漏项)

**(5) 随机化对象改正——干预盲(a)**:
应盲者**非"标的身份"而是「干预项与评分键」**——哪一项被改、期待何方向,**评分席一律不知**;评分键仅**材料构造者与协议审计者**持有。
**封堵**:需求特征(demand characteristics)——席位一旦知道自己在做A/B对照,即会配合实验者预期作答。
**我方漏因**:v2把"盲"的对象锁定在标的身份上,未意识到真正需要盲的是干预设计本身。

**(6) 安慰剂对——特异性(b)·我方真窟窿**:
改**版式/叙述顺序/无关规模数字/不应进入该轴之信息**,**预注册"档位不应变化"**。
**封堵**:缺此则**"见什么都动的钝尺"会被误判为灵敏**。
**与(4)配对使用**:**机制干预测敏感性、安慰剂测特异性,两者缺一不可**——只做(4)则无法区分"尺子对机制敏感"与"尺子对任何变化都敏感"。

**(7) 无尺子基线臂——增量价值(c)**:
同一材料另设一席**仅用一般商业判断(不给尺子)**,与尺子臂配对比分。
**判据**:**若两臂结论无差,则尺子无增量,只是把常识翻译成术语**。
**锁定条款**:此臂结论对框架本身具**否证力**,**不得因结果难看而事后取消**(预注册锁定·与v1.1装置5同构)。

### 并采纳(段C其余建议·ADJ-0725-08①d)

- **先验基线记录**:评审席看材料**前**先封存"仅凭既有知识会给的档位与身份猜测";
- **逐项证据溯源**:三栏制(观察事实/中间推断/档位结论)+证据ID;
- **缺失与冲突证据测试**:预注册期望=降置信/收缩区间/转无法评级;
- **合成机制锚点**;**失败优先报告**;**顺序与版本平衡**;**干预合理性审计**。

### 门0 · 协议完整性
- 评分**前**封存:尺子版本、终点(endpoint)、阈值;
- 评分席**未见**评分键与结果;
- 必填项与证据ID齐备;排除(exclusion)按预注册执行。
- **失败处置**:任一关键项失败 → 结论**只能写"协议失效"**,**不得宣称通过**。

### 门1 · 机制敏感性与安慰剂稳定性(阈值照段C建议预注册)
| 指标 | 阈值 |
|---|---|
| 机制干预按预期方向 | **≥75%** |
| 反向变动 | **≤10%** |
| 重大干预之档位中位变化 | **≥1档** |
| 安慰剂不动 | **≥90%** |
| 缺失证据响应(降置信/收缩/转U) | **≥75%** |
- **复现要求**:须在**≥2个隔离席位或独立运行簇**同向复现。

### 门2 · 增量价值
- 尺子臂对基线臂**配对净得分至少高15个百分点**;
- 且须出现于「机制方向 / 安慰剂稳定 / 证据落地」**三子项之至少两项**;
- **不得靠虚增"无法评级"比例取巧**。
