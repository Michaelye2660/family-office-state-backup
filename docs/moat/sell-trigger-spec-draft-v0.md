## 〇、设计前提:先说清这套东西"不是什么"

**卖出触发器 ≠ 錯殺帶。** 二者标尺不同,混用即误用(ADJ-0726-03⑨ 口径裁定已明):

| | 錯殺帶(門B) | 卖出触发器(本制度) |
|---|---|---|
| 回答的问题 | **何价位值得投入新资金** | **当初的买入论点是否已经失败** |
| 管辖对象 | **新建仓** | **存量持仓** |
| 与价格的关系 | 核心是价格 | **原则上不看价格**(见 §三-0) |
| 不对称性 | 刻意偏低(错过≠事故) | **不设不对称**——论点塌了就是塌了 |

**故:一个标的"今天不值得新买"与"应该卖出"是两件独立的事**,前者由帶回答,后者由本制度回答。**永远不得以帶值作为卖出判据。**

**并须直面一个不舒服的推论**:采本制度即等于承认「**入场标准与持有标准允许不一致**」——若今天空仓我不会买它,但因为已经持有所以继续持有。此立场**可辩护**(交易成本、税、择时风险、永久资本属性),但**不是无代价的**。本草案选择**显式承认**而非回避,并以 §四「甲+ 中间档」承接其代价。

## 二、五条触发器(草案 · 逐条须预注册基准)

> **总设计**:每条对应「**当初买入论点的一根支柱**」。支柱塌了才卖,不是变贵了才卖。
> **预注册强制**:每条在**买入时(或本制度生效时,对存量补做)**须登记**基准值**;无基准值者,该条对该标的**记为「不可判」而非「未触发」**——两者必须区分(此即体检发现之教训)。

### T1 · 质量门失守
**判据**:MDG 由预注册档位**下降 ≥1 档**,且该降档**经陪审确认**(非降档期临时件、非单方判定)。
**凭据**:MDG 评级卷 + 陪审裁决书 commit。
**为何是它**:買入之首要前提即「生意够好」。质量门塌了,其余皆无意义。

### T2 · 现金创造力破线
**判据**(两者之一):
(a) **自由现金流/股**连续 **两个完整财年**低于预注册基准的 **80%**;**且**按 ADJ-0726-01⑪ 通则**同报绝对额与股数**——若每股下降主要由股数增加(增发/摊薄)所致,记 T2 亮;**若每股维持而绝对额持续下滑,同样记 T2 亮**(防回购掩盖);
(b) **经营现金流转为负**且非季节性,连续两期。
**凭据**:SEC/监管申报一手(XBRL `companyfacts` 可机械取)。

### T3 · 资本配置事故
**判据**(两者之一):
(a) 商誉或无形资产**减记 ≥ 预注册基准净资产的 10%**;
(b) 单笔或连续收购导致**净负债/EBITDA 连续两年 > 4.0x** 且无明确去杠杆路径。
**凭据**:监管申报一手。
**为何是它**:多数「优质生意变坏」不是经营塌的,是买错东西买塌的。

### T4 · 竞争地位实证倒退
**判据**:核心业务之**份额或定价权**出现连续 **两期**可观测倒退,**且须第三方或监管申报口径**——**公司自述不足以判 T4 亮,亦不足以判 T4 未亮**(无第三方口径时记「不可判」)。
**凭据**:第三方份额数据、监管申报、竞对披露之交叉读数。

### T5 · 论点前提消失(逐案预注册)
**判据**:**买入时所登记的那一条具体前提**被证伪。
**示例**(现有个案条款可直接归入):DHR「整合失败/商誉减记」;BDX「分拆后新 BD 之纯 MedTech 定位不成立」;NVO「制药域校准口径建成后仍不过质量门」。
**凭据**:逐案预注册时一并写明「什么算被证伪」。
**为何是它**:前四条是通用的,而每笔买入总有一条**只属于它自己**的理由;若不预注册,事后必然被重新解释。

## 三、判定与动作映射

### 3-0 · 价格不入判据(硬条款)
**五条之中无一条含价格。** 股价下跌**本身**永不构成卖出触发;股价上涨亦不构成。理由:两池规则已定「已建满持有仓跌了不动」,若再让价格进入卖出判据,即自相矛盾。

### 3-1 · 映射(沿用既有口径)
| 亮灯数 | 动作 |
|---|---|
| **0** | **持有**·无动作 |
| **1** | **减半 + 升入加密监控**;减半执行时点由委托人定,CGM 不催办 |
| **≥2** | **退出 + 书面承认论点失败**(须落 〔M〕,不得静默退出) |

### 3-2 · 「不可判」不等于「未触发」(本制度之核心纠错)
- 某条因**缺基准值**或**缺第三方口径**而无法判定者,一律记 **「不可判」**;
- **「不可判」不计入亮灯数,但须计入「体检完整度」并在卷内显示**;
- **若五条中 ≥3 条「不可判」,该标的之体检结论一律记「协议失效·结论不成立」**,不得以「0 亮灯」宣称持有有据 —— 此条直接对应本次体检所暴露之病:**四条指纹全数「数据不足」时,不得读作「安全」**。

## 四、甲+ 中间档(承接 §〇 之代价)

某持仓若**以今日标准评估不过双门**(質量門不过 ∨ 門B 未过),该事实**不构成卖出理由**,但构成三项后果(ADJ-0726-03⑨ 已裁,本草案承接并具体化):

1. **不加新钱**;
2. **升入加密监控**;
3. **年度须显式重新论证「仍值得持有」** —— **本草案建议其形式为**:一页纸、三段式——(a) 当初买入的论点原文照录;(b) 该论点今日是否仍成立,逐句对照;(c) 若今日空仓是否会买入;**若 (c) 答"不会"而 (b) 答"仍成立",须解释这两者为何不矛盾**。论证不成立则**转卖出触发器复核**。

> **为何是一页纸而非简化版門A**:門A 是一整套四席深查,产能上不可能对每个存量持仓每年跑一次;而三段式的**关键在 (c) 那一问**,它把「入场标准与持有标准不一致」这件事**每年强制摆到台面上一次**,而不是让它默默存在。**能答就答,答不出就该走复核。**

## 五、执行机制(针对「规则写了但不运行」之病 · 本草案最要害一节)

**体检发现该机制从未有过一次执行留痕。故本节之设计目标不是"更严",而是"能被证明在运行"。**

1. **频率**:每季度一次全扫(对齐财报季),**外加**任一标的财报落地后 5 个交易日内单标的扫;
2. **责任人**:CGM 执行;GM 核签;
3. **凭据形态**:每次全扫**必须产出一份带日期的卷**落 `docs/holdings-review-YYYY-MM-DD.md` 并 commit;**卷内每条触发器须写「判定 + 凭据链接/accession + 数据日期」**;
4. **未做之后果**:**逾期未扫即为 breach**,由周复盘固定项(ADJ-0726-04②/ADJ-0726-02⑧ 已立之全库机械扫描)自动检出并报;
5. **一个月后如何知道它在运行**:`ls docs/holdings-review-*.md` 与 `git log` 即可机械核 —— **本条即为七问之答**;
6. **入〔K-0〕制度动作事件触发器表**,与其它制度动作并列受步0 增查监督。

> **本节系对 ADJ-0726-03③ 七问判别测试之自我应用**:触发事件=季度/财报;责任人=CGM;具体动作=出卷落库;不可伪装凭据=commit 与 accession;凭据匹配之判定=卷内逐条;未做之后果=breach;一月后如何知其运行=`ls` 与 `git log`。**七问全可答,方敢提交。**

## 六、对存量之过渡安排

- 本制度生效时,现有持仓**须补做预注册**(登记各条基准值);补做前,各条一律记「不可判」;
- **补做本身即为第一次全扫**,其产出即第一份正式体检卷;
- **过渡期内不因「不可判」而生任何减持义务** —— 缺的是判据不是理由。

## 七、本草案自知之弱点(先自曝,不等外部指出)

1. **阈值仍是拍的**:T2 之「80%」、T3 之「10%」「4.0x」、T4 之「两期」均**无运行数据支撑**,与 GM 于 ADJ-0726-04① 自陈之立规缺陷**同型**。**建议:先以「不可判/亮/未亮」三态运行两个季度,用实际读数标定阈值,再定稿**——即**先跑再定数**,而非先定数再跑。
2. **T4 极可能长期「不可判」**:第三方份额数据在本环境多不可得(见 `docs/data-source-fallback-map.md` 仍无解清单)。若 T4 长期不可判,§3-2 之「≥3 条不可判即协议失效」可能被频繁触发 —— **此为设计张力,须 GM 裁**:是放宽 T4 凭据要求,还是接受「协议失效」之高频出现(后者至少诚实)。
3. **T5 对存量之补做有后视镜风险**:今日回头写「当初买入的论点」,难免受已知结果影响。**建议**:补做时须注明「系事后追记」,并**尽可能引用当时的〔M〕条目原文**而非重新表述。
4. **与既有 MDG 降级指纹之关系未理清**:各标的已有的降级指纹(如 TMO 四条、IDXX 四条+C3-L)与本制度 T1 有重叠。**建议**:MDG 降级指纹**归入 T1 之凭据链**,不另立一层,避免同一事实被计两次。
