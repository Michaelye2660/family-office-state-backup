## 〇、设计前提:先说清这套东西"不是什么"

**卖出触发器 ≠ 錯殺帶。** 二者标尺不同,混用即误用(ADJ-0726-03⑨ 口径裁定已明):

| | 錯殺帶(門B) | 卖出触发器(本制度) |
|---|---|---|
| 回答的问题 | **何价位值得投入新资金** | **当初的买入论点是否已经失败** |
| 管辖对象 | **新建仓** | **存量持仓** |
| 与价格的关系 | 核心是价格 | **原则上不看价格**(见 §三-0) |
| 不对称性 | 刻意偏低(错过≠事故) | **不设不对称**——论点塌了就是塌了 |

**故:一个标的"今天不值得新买"与"应该卖出"是两件独立的事**,前者由帶回答,后者由本制度回答。**永远不得以帶值作为卖出判据。**

**并须直面一个不舒服的推论**:采本制度即等于承认「**入场标准与持有标准允许不一致**」——若今天空仓我不会买它,但因为已经持有所以继续持有。此立场**可辩护**(交易成本、税、择时风险、永久资本属性),但**不是无代价的**。本草案选择**显式承认**而非回避,并以 §四「甲+ 中间档」承接其代价。

**动作**:**H 类一票即退出**,不进 §3-1 亮灯映射,不与 A 类合并计数。

> **⚠️ 须对委托人明说,以免误读为「又加限制」**:**H 类不增加任何日常工作量。**
> 其判据全部是「**发生了就是发生了**」之**离散事件** —— **无须计算、无须建基准、无须取连续序列、无须任何估值判断**;平时一律记 `N`,只在真出事那一天才有内容。

## 三、判定与动作映射

### 3-0 · 价格不入判据(硬条款)
**A 类四条与 H 类三条之中,无一条含价格。** 股价下跌**本身**永不构成卖出触发;股价上涨亦不构成。

**理由二条**:
1. **(我方原理由)** 两池规则已定「已建满持有仓跌了不动」,若再让价格进入卖出判据,即自相矛盾;
2. **〔v3 增 · 外审 A1 采纳 · 比原理由更根本〕**:「把下跌设为卖出条件,**会把永久资本变成顺周期资本,在市场压力最大时机械减仓**。」
   → **原理由说的是「与既有规则冲突」,这一条说的是「与资金性质本身冲突」。** 后者即使两池规则不存在也成立。

> **【v1 必须写死之界分 · 否则本草案自相矛盾】** §3-B 之触发含估值(而估值含价格),表面上与本条冲突。**界分如下,不得混用**:
> - **本条(3-0)管的是「卖出判据」** —— 价格**永远**不得作为**产生卖出动作**之理由。**T1–T4 之中无一条含价格,§3-B 亦不产生卖出动作。**
> - **§3-B 管的是「审视义务之触发」** —— 价格/估值**可以**触发「**必须写一页论证**」这件事,**但那份论证之结论仍须由 T1–T4 之基本面判据支撑**;**论证不得以「太贵了」为唯一理由而得出减持结论**。
> - **一句话**:**价格可以叫醒你,但不可以替你做决定。**

### 3-1 · 映射(**v3 改 · 外审 C2 采纳 · 由三档改四档**)

| 亮灯数 | 动作 |
|---|---|
| **0** | **持有**·无动作 —— **⚠️ v4 改:本行之适用前提为该标的仍处「可投」状态。若已转「不可投」,则 0 亮灯不再等于无条件持有,须叠加 §6-A 之退出推定**(ADJ-0726-08⑨) |
| **1** | **隔离状态**:冻结新增 + 升入加密监控 + **每月复核** + **启动不可暂停之升级时钟**。**单一项首次触发不产生减持** |
| **2** | **减半 + 书面记录**;减半执行时点由委托人定,CGM 不催办 |
| **≥3** | **退出 + 书面承认论点失败**(须落 〔M〕,不得静默退出) |

**棘轮条款(v3 新增 · 防「拖过去就没事」)**:
- **同一项连续两个审查周期仍触发 → 按两项处理**(即自动升至减半档);
- **已减半后,下一周期仍有两项触发 → 完全退出**;

> **CGM 判读**:新档在**约束强度上不弱于原案**(有时钟与棘轮,拖不过去),**但误报成本更低**。**此为本次修订中唯一放宽扣扳机速度之处,且以时钟+棘轮对冲。**

> **本表之管辖边界**:仅 A 类触发器 T1–T4 进入本表。**H 类(§二-H)不进本表——H 类一票即退出**。**§3-B 极端溢价复议触发器不进入本表、不产生亮灯、不产生任何减持义务**。

### 3-2 · 「不可判」不等于「未触发」(本制度之核心纠错)
- 某条因**缺基准值**或**缺凭据口径**而无法判定者,一律记 **「不可判」**;
- **「不可判」不计入亮灯数**;
- **【v1 改·GM 意见③:删拍定数·改结构规则】结论行须并列两栏:「亮灯数」与「不可判数」。**
- **只要「不可判数」> 0,结论一律不得书「持有有据」,只能书「未见触发 · N 项不可判」。**
- **理由(GM 原文之意)**:无数字、可机械核验、**约束强度高于原「≥3 条」之拍定阈值**——因其对**任一**不可判即生效,而非等到三条。
- 此条直接对应本次体检所暴露之病:**四条指纹全数「数据不足」时,不得读作「安全」**。

> **【v2 增 · ADJ-0726-06④ · 过渡期专用结论词(标准词,不得自行变体)】**
>
> **标准词 = 「未见触发 · N 项不可判 · 基准未标定」**
>
> **卷首一次性说明其含义(每份体检卷须写一次)**:**这句话既不是警报,也不是背书。** 它的意思只有一个——**在已能判的范围内没有发现触发,而尚有 N 项因缺基准或缺凭据无法判定。**
> **防滥用条(CGM 提·GM 采认·入正文)**:**该结论行不得反过来用作减持理由。** 「说不清楚」不是「有问题」;**缺的是判据,不是理由**(与 §六同源)。

#### 3-2-A · 四态判定(**v3 改 · 外审 B1 采纳 · 由三态改四态**)

| 态 | 定义 | 是否计入「不可判数」 |
|---|---|---|
| **T** 已触发 | 判据成立 | — |
| **N** 已判定未触发 | 判据不成立,**且有凭据** | — |
| **U** 应有数据但无法判定 | 数据**本应可得**而未能取得,或基准未预注册 | **计入** |
| **NA** 不适用 | 按预注册规则不适用,**或数据尚未到法定应披露时间** | **不计入** |

> **🔴 本改之要害(CGM 须自我更正一处)**:我方原三态把「**财报还没出**」与「**应该有却取不到**」混为一谈。
> 后果是:若「财报还没出」也计入不可判,则**任何时点都必然不可判,结论行永远是「N 项不可判」**。
> **故 §七-5 所称「过渡期内『持有有据』长期无法书写系有意为之之诚实」,有相当一部分并非诚实,而是口径缺陷。此处更正。**

**NA 之防滥用四条件(外审原文 · 防「把不利数据改成不适用」)**:**NA 必须在预注册时确定**;任何「由适用改为不适用」之变更须 ①在**下一期数据产生前**完成;②由执行人与**独立复核人共同批准**;③说明**替代指标**;④**仅对未来期间生效**。

#### 3-2-B · U 状态之后果阶梯(**v3 新增 · 外审 B4 采纳 · 并按 C1 之「缺失归因」二分**)

> **CGM 之二分裁(外审 B4 与我方 §六「不生减持义务」原本冲突,此二分化解之)**:外审已把两种缺失分开——**有记录之市场范围技术故障**可延期;**发行人自身不披露、拒绝提供或文件矛盾不得延期**。据此:

| 缺失归因 | 处置 |
|---|---|
| **(甲) 我方取数能力所限** | **不生任何减持义务**。依据:本环境硬边界确凿(6 日以前逐日 EOD 全无途径、个股官方结算 EOD 不可得、部分端点套餐受限)。**「缺的是判据,不是理由」在此情形下成立** |
| **(乙) 发行人侧不披露／拒绝提供／文件自相矛盾** | **按下列阶梯处置**。依据:**这本身就是关于该公司的信息**,不是我方的取数问题 |

**(乙) 类之阶梯**:
- A 类 U → **10 个工作日**内补齐;逾期则进**隔离状态**并每周复核;

### 3-3 · 先跑再定数(硬条款 · GM 意见⑤「全草案最应保之条款」)

**本制度之一切阈值,在积累两个季度实际读数之前,一律标注「未标定 · 仅记录」,不得作为动作依据。**

- 运行方式:三态(**触发 / 未触发 / 不可判**)照常判、照常出卷,**但阈值不锁死**;
- 两季后**以实际读数标定**,再定稿;
- **理由**(与 ADJ-0726-04① GM 自陈之立规缺陷同源):**阈值由数据算出,不由裁量拍出**。

> **【v3 改 · 外审 A5 采纳 · 阈值可改之时间界】** 原表述「阈值一经预注册,不得因结果不佳事后修改」须靠**动机判断**("何谓结果不佳")。改为外审之可机械判定口径:
> **阈值只能在「尚未看到下一期数据」之前修改;一旦相关事件已发生或已接近触发,不得追溯改写。**
> **每次修改须记录:修改时点、当时最新数据之截止日、修改理由、条文 commit sha。**

> **【v2 增 · ADJ-0726-06③ · 标定动作之到期日(硬条款)】**
> **到期窗 = 制度生效日起、第 2 个财报季结束后 30 日内。** 生效日 = **2026-07-26**(§五即刻生效之日)。
> **逾期即 breach**,按 §五 后果条处置;**已入〔K-0〕表**受步0 增查监督。
> **本条所防者(GM 定性照录)**:正是「**先跑再定数**」退化为「**先跑再忘**」——GM 记为「CGM 本轮最有价值之加提」。

### 3-A · 减持之四类来源与分流(v1 新增 · GM 意见⑨-a · 防混管)

|---|---|---|
| **(一)论点失败** | ≈ **門A 降档** | **归本制度**(T1 / T4) |
| **(二)集中度与风险管理** | **超配回归,非论点失败** | **归红线体系**(中港 ≤10% / 科技 25–30% / 单注 2–4% / 猎场桶 6%)——**不归本制度**。**委托人腾讯减持至约 200 万即属此类**(系委托人既定决定、非制度产物;时点由委托人定,**CGM 不催办、不建议时点**) |

### 3-B · 极端溢价复议触发器(v1 新增 · GM 意见⑨-b 立项 · **强制审视,不强制动作**)

> **定位**:本条**不是第五条卖出触发器**——**不计入 §3-1 之亮灯数**;**其唯一产出是一份书面论证,不产出任何买卖指令**。

| 项 | 内容 |
|---|---|
| **触发** | 估值达**预注册之极端读数**:(i) **其自身历史分位极值**;或 (ii) **反向 DCF 隐含之必要增速,超过该生意历史上从未达到过之水平**。**(ii) 硬于「多少倍 PE」,优先采**——倍数是相对量,随利率与会计口径漂移;而「**该生意自己从未做到过的增速**」是一个**可被证伪的事实陈述** |

#### 3-B-1 · 反向 DCF 之口径矩阵与稳健性判据(v2 · ADJ-0726-06②)

**GM 裁定:不定单一口径,改「口径矩阵 + 稳健性判据」。**

- **不由 GM 拍定折现率／终值增长率**(与 ADJ-0726-04① 之教训一致);

- **触发仅在三组皆超**该生意**历史最高实现增速**时成立 —— **稳健性代替精度:要触发,须在所有合理参数下皆极端**;
- **历史窗口 = 该公司自身可得之最长 SEC XBRL 序列**(不拍年数),**须报窗口长度**;
- **(ii) 优先于 (i)** 照旧(GM 采认 CGM 之第二理由:历史估值分位路径因「6 日以前逐日 EOD 全无途径」之硬边界短期不可行)。

> **【CGM 核验之一项重要发现 · 本条并非新建】** 本口径与我方**买入侧既有之「門5e 锚二自算规则」同源**:
> 門5e 已规定「反向 DCF 锚二**必须自算市价隐含增长率 g 且含敏感性区间**(矩阵形态),**单点值不合格**」;其 v1.4 补款更规定「基数年 FCF 受一次性/外生项污染时,须并列**正常化 FCF 口径**隐含 g 敏感行,**单口径不合格**」。

**三组参数之方向定义(须先写死,否则「保守/乐观」歧义)**:
- 折现率 **↑** → 隐含必要增速 **↑** → **更易触发**;终值增长率 **↑** → 隐含必要增速 **↓** → **更难触发**。

## 四、甲+ 中间档(承接 §〇 之代价)

某持仓若**以今日标准评估不过双门**(質量門不过 ∨ 門B 未过),该事实**不构成卖出理由**,但构成三项后果(ADJ-0726-03⑨ 已裁,本草案承接并具体化):

1. **不加新钱**;
2. **升入加密监控**;
3. **年度须显式重新论证「仍值得持有」** —— **本草案建议其形式为**:一页纸、三段式——(a) 当初买入的论点原文照录;(b) 该论点今日是否仍成立,逐句对照;(c) 若今日空仓是否会买入;**若 (c) 答"不会"而 (b) 答"仍成立",须解释这两者为何不矛盾**。论证不成立则**转卖出触发器复核**。

> **【v1 增·GM 意见④】(c) 之答案不绑定动作**:「今日不会买」与「今日该卖」**是两个判断**(入场门槛 ≠ 持有门槛·ADJ-0726-03⑨ 口径裁定)。故 **(c) 答"否"仅触发「不加新钱 + 升入加密监控」,明文不构成减持理由**;**(c) 之价值在于信息与年度显式论证,不在于产生动作**。

> **为何是一页纸而非简化版門A**:門A 是一整套四席深查,产能上不可能对每个存量持仓每年跑一次;而三段式的**关键在 (c) 那一问**,它把「入场标准与持有标准不一致」这件事**每年强制摆到台面上一次**,而不是让它默默存在。**能答就答,答不出就该走复核。**

**(a) 时钟须错开起点** —— 若所有持仓同日启钟,到期日撞车将造成**同步退出波**(在压缩窗口内卖出多个仓位,**执行价由运气决定**)。**按标的分散起始日**,不得批量同日启钟。

**(b) 零税负降低的是纠错成本,不是举证标准** —— 港/新境外资本利得零税使「卖错再买回」成本低,**此点支持采纳倒置**;但**不得以可逆性作为随意性之许可**,退出仍须书面论证。

#### 6-A-4 · 与 §3-1 映射表之关系(**默认方向变更之实质影响 · ADJ-0726-08 执行注所令之回改**)

**两条线须分清,不得混用**:

| 线 | 触发 | 产出 |
|---|---|---|
| **A 类亮灯映射(§3-1)** | 触发器亮灯 = **「当初买入论点已失败」** | 0/1/2/≥3 → 持有／隔离／减半／退出 |
| **退出推定(§6-A)** | 质量门转**「不可投」** = **「若今日空仓,不会买它」** | 举证倒置 + 时钟 + 到期默认减持 |

**叠加规则**:
- **§3-1 之「0 亮灯 = 持有·无动作」,其适用前提是该标的仍处「可投」状态**;
- **若已转「不可投」,则 0 亮灯不再等于无条件持有** —— 须叠加 §6-A 之退出推定,**即「无触发」与「有资格继续被持有」自 v4 起是两个判断**;
- **反向不成立**:A 类亮灯**不自动**使标的转为「不可投」(质量门之判定另有其程序)。

> **CGM 须明说之一句**:v3 之前,「0 亮灯」是持有的**充分理由**;**v4 之后,它只是必要条件之一**。这就是「默认方向由持有改为退出」在条文上的实际含义。

**外审 (a) 之判定**:我方现行制度 = 外部之「**方案二 入场—持有双轨制**」;外部**倾向方案三「可反驳的退出推定」**。
**外部对方案二之五条代价,CGM 逐条自核全部成立**,尤其:「**继续持有的举证责任常常会在实践中悄悄消失**」——**我方中间档 (iii)「年度须显式重新论证仍值得持有」此前一次都没有执行过**。
**外部并给方案二可靠之四前提,CGM 机械自核仅满足零至二条**:存量门足够明确 ❌／有时间限制 🟡／有书面举证 🟡／**独立复核 ❌**(v3 §五已修补此条)。

| | **选项 A(维持现行 · 默认持有)** | **选项 B(采纳外审 · 默认退出可反驳)** |
|---|---|---|
| **默认方向** | **持有**。须 A 类亮灯或 H 类触发方生动作 | **退出**。质量门转「不可投」后,**继续持有须提交书面反证** |
| **不可投之后果** | 中间档三后果(不加新钱／加密监控／年度重新论证) | 五件事:冻结新增／**原因分类**(结构性恶化·暂时性不确定·证据不足·制度定义变化·纯数据质量)／**举证责任倒置**／**设失效期**(不得永久滚动)／**到期默认分阶段减持或退出** |
| **代价** | 「不可投但可永久持有」之制度悖论;举证责任在实践中悄悄消失(**已实证**) | 制度更复杂;须维护原因分类与时钟;**可能反复续期**;若复核者与持有人利益一致,书面反证流于形式 |
| **防架空** | — | **续期次数受限;第二次续期须由原决策链之外的人批准** |

**CGM 之判读(供裁,不自决)**:
- 选项 B **不等于「因不可投而卖出」** —— 它只是把「谁必须开口」换了个方向:A 是「想卖的人要举证」,B 是「想留的人要举证」。**B 的默认后果有时钟,但每一次续期都是合法的,可以一直续下去**——只要每次都真的写出理由。
- **体检第一卷已实证的事实是**:五个医疗类标的中四个处于「不加新钱、只持有、无退出机械」,**而唯一能约束它们的 (iii) 从未执行**。→ **在 A 之下,「年度重新论证」是一件没人被迫做的事;在 B 之下,不做的默认结果是减持。**
- **故此项之真实分歧不在「卖不卖」,而在「不写论证时会发生什么」。**
