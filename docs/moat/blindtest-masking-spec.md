# 盲测二次遮蔽规范 v1(2026-07-25·委托人「遮蔽」令)

> **立规缘起**:v1.1 §六匿名盲测首次实测中,CGM遮蔽复核发现——一次遮蔽(去公司名/品牌名/产品名+绝对金额比率化)在**大盘平台域天然失效**:大平台的经营数据本身即指纹(月活量级组合、分部结构、财年制、公开唯一监管事件)。CGM曾建议"接受识别性+开卷自报"之妥协方案;**委托人令「遮蔽」= 不接受妥协,要求做到真盲**。本规范据此立。

## §一 适用与层级

- 适用:v1.1 §六盲测试运行之全部案卷(现=公司T/公司E/公司M三包);后续域尺盲测同此。
- **两版制**:①**一次遮蔽版**(原始取数包·含精确时点与量级)→ 存 `blindtest-sealed/` 类隔离位,**盲测席禁读**,供开封后校准与可验证性回溯;②**二次遮蔽版**(本规范处理后)→ 唯一交付盲测席之卷。

## §二 五类指纹与处理规则

| 类 | 指纹形态 | 处理规则 |
|---|---|---|
| **1. 时点** | 具体年月/季度标签/财年起讫月 | 全部**相对化**:最新已报期=**T0**,往前 T-1/T-2…;年度=**FY0/FY-1/FY-2**…;**财年起讫月一律删除**(仅注"财年非日历年制"或"财年=日历年") |
| **2. 事件日期** | 监管处罚日/并购交割日/政策施行日 | 改为**相对时序**("约T-5年""T-1年内""T0前一季度生效") |
| **3. 绝对量级** | 用户数/开发者数/装机数等唯一可识别量级 | **降精度至数量级+相对位序**(如"14.32亿"→"十亿级·该细分最大";"9.5亿"→"接近十亿级·居首";"约1.8亿"→"亿级") |
| **4. 辖区与机构** | 具体国别/监管机构名/法规名 | 保留**监管机制内容**(捆绑/数据闭环/自我优待/排他/价格干预)与**强度层级**;辖区改**主要辖区A/B/C**;机构名与法规名删除 |
| **5. 结构指纹** | 分部命名/业务组合描述过细 | 分部改**功能中性名**(分部一/二/三);业务描述保留**经济性质**(订阅制/交易抽成/广告变现),删除行业特有专名 |

## §三 保真底线(不得遮蔽掉的东西)

遮蔽以**不损尺子可评估性**为界。以下必须保留,否则该项按"未取到"处理而非模糊化:
1. 各轴读数的**方向与幅度**(增速%、利润率%、占比%、比率、倍数);
2. **时序次序**(哪个在前哪个在后)——v1.1轴1要求领先/同步/滞后标签,次序丢失则轴1不可评;
3. **机制描述**(转换成本从何而来、监管改变了什么机制);
4. **口径标注与置信等级**(一手/二手/第三方估算/未取到/冲突并列);
5. **缺口与冲突清单**——反证申报是v1.1观测证据闸的组成部分,不得因遮蔽删减。

## §四 代价申报(强制·入试运行报告)

二次遮蔽必然带来三项代价,须逐案如实申报:
1. **可验证性下降**:盲测席无法回溯核对原始来源(原始版在隔离位);
2. **时序精度损失**:相对化后无法对齐外部宏观事件(如利率周期、行业周期);
3. **残留识别风险不归零**:业务组合的经济结构本身仍可能被推断出身份——**故盲测席仍须开卷自报"是否已识别标的、依据为何"**,该自报作为读数之一入试运行报告(此系原方案(c)项之保留,与"加强遮蔽"并行不冲突)。

## §五 执行与复核

- 执行主体=CGM(机械操作);**复核=逐包出「残留指纹清单」**,列明处理后仍可能识别的项与理由,随卷交GM;
- 遮蔽处理**不得改动任何数值本身**(仅改标签与精度呈现);数值改动=数据造假,绝对禁止;
- 二次遮蔽版与一次遮蔽版之对应关系(替换表)存隔离位,开封时用于还原比对。
