## B · 机制证据

**B1 · 需求侧粘性（领先／同步）**
- **M365 商用付费席位同比 +6%**（一手·同步）；装机基盘扩张**主要来自中小企业与一线员工**，非大企业席位增量。
- **Copilot 付费席位超 3,000 万**；本季**净新增付费席位环比翻倍以上**（一手·领先）。
- M365 消费云收入 +24%（固定汇率 +22%），**由 ARPU 增长驱动**；消费订阅数 +7%（一手）。
- 大型部署实例（一手·点名）：NHS England 向 **505,000** 名临床与员工推 Copilot（试点显示日均省 43 分钟）；KPMG 全球 276,000＋；HSBC 承诺 200,000 席；AstraZeneca／Boeing／Infosys／P&G／Stellantis／TCS／Wells Fargo／Wipro 等各购 60,000＋。

**B2 · 供给侧／生态（领先）**
- **GitHub Copilot 5,000 万用户**；本季引入**用量计费**，新模式生效后仍见企业席位增长且消耗式收入显著；**Copilot 收入环比加速 60%＋**。
- GitHub 总用户 **2.25 亿**；**《财富》500 强逾 90%** 使用；**GitHub 上每三个 pull request 有一个涉及 agent**（一手）。
- Microsoft Purview 已审计**逾 150 亿次 Copilot 交互**（同比 +360%）。

**B3 · 定价权实证（领先／同步）**
- **ARPU 增长本季由 Copilot／E5／E7 早期采用驱动**（一手·管理层归因）——即**高价档位组合上移**。

- M365 商用产品收入 **+19%，超预期**——管理层归因于**大额长久期合同**导致 Windows Commercial 本地部分之期内收入确认较高（**⚠️ 此项系确认时点效应，非纯需求信号**）。
