## 1. 结论档位

**MDG-3 有沟**

Amazon 的护城河真实且部分机制正在增强，尤其是 AWS 的基础设施规模、自研硅、开发者工作负载与长期产能承诺；但客户集中度、资本开支向现金流的转化、零售侧自然留存三项相互独立的威胁尚未闭合，不符合 MDG-4 所要求的“仅余单一长期威胁”，亦缺少足以跨越 MDG-5 观测证据闸的流失率、续订率、提价吸收或监管挡门证据。[B1][B3][B6][D1][D6]

## 2. 关键理由

1. AWS 积压达 **$496B**、2027 年大部分产能及 2028 年相当部分产能已被预订，显示客户对算力基础设施作出多年承诺，但 Anthropic 与 OpenAI 两家的占比未知，不能把总积压直接等同于广泛、自然的客户粘性。[B1][C1][D1]
2. AWS 同比增长 **36.7%**、连续第五个季度加速，自研芯片与 AI 业务收入运行率均已逾 **$25B**，说明规模、硅栈和工作负载之间的增强回路正在形成。[B2][B3]
3. 零售侧同时具备平均价格低 **14%**、同日生鲜覆盖 **2,300** 座城市及月活客户增长逾 **50%** 的履约与分发优势，但价格读数来自管理层转述第三方，且缺 Prime 续订率与流失率，不能排除低价、捆绑或补贴驱动。[A3][B4][C5][D6]
4. AWS 营业利润率同比改善在剔除衍生品收益后仍有 **520bp**，支持其成本与利用率优势，但结构性效率与周期性产能优化未拆分，故不能把全部改善计为不可逆护城河。[B5][C2][D4]
5. TTM 自由现金流由流入 **$18.2B** 转为流出 **$7.6B**，同期资本开支增长 **64%**、全年指引约 **$220B**，且单位算力收益与“维持性／扩张性”资本开支拆分缺失，价值捕获仍是独立威胁。[B6][C4][D2][D8]

## 3. 可证伪条件

### 降级至 MDG-2：以下任一组合出现即触发

- **需求与集中度组合**：AWS 连续两个季度同比增速低于 **20%**，同时 backlog 同比停止增长或下降；或公司披露 Anthropic 与 OpenAI 合计占 AWS backlog／新增承诺超过 **50%**，且其中一家削减、延期或取消至少 **20%** 的既有承诺。[B1][B2][C1][D1]
- **资本效率组合**：TTM 自由现金流连续四个季度为负，同时年化资本开支仍不低于 **$200B**，且 AWS 剔除一次性项目后的营业利润率同比改善降至零或转负。[B5][B6][C4][D2]
- **零售自然粘性组合**：公司披露 Prime 续订率低于 **90%**，或十二个月 cohort 留存同比下降超过 **5 个百分点**；又或在剔除促销、运费补贴与捆绑获客后，生鲜月活连续两个季度同比负增长。[B4][C5][D6]
- **前瞻需求组合**：集团收入指引连续两个季度落在个位数增长，且管理层将减速明确归因于终端需求或客户工作负载迁移，而非基数、汇率或供给约束。[B7][C3][D3]

### 升档至 MDG-4：须同时满足

- AWS 披露的客户结构显示 Anthropic 与 OpenAI 合计占 backlog／新增承诺低于 **25%**，并提供广泛客户 cohort 的续订率不低于 **95%** 或净收入留存率不低于 **110%**；该读数须剔除 credits、折扣、默认分发与捆绑影响。[B1][C1][D1]
- TTM 自由现金流连续两个季度转正，同时年化资本开支仍不低于 **$200B**，并披露单位算力收入、单位算力毛利或投资回收期持续改善，证明高投入主要用于扩张而非维持竞争均势。[B6][C4][D8]
- 零售侧披露 Prime 续订率不低于 **90%**、十二个月 cohort 留存稳定，且剔除促销、运费补贴与捆绑后仍保持正向用户增长或购买频次增长。[B4][C5][D6]
- Q3 所示减速不演化为持续需求转弱，且 AWS、第三方卖家服务、广告和订阅中至少三项连续两个季度保持双位数增长。[A3][B7][C3][D3]

### 进一步升档至 MDG-5：额外观测证据闸

须出现至少一项可重复观测的机制证据，例如：在实质提价或取消 credits／补贴后，AWS 广泛客户 cohort 的流失率无显著上升；或监管、牌照、基础设施接入及规模经济形成可验证的进入挡门判例，仅凭当前积压、增速和管理层前瞻表述不足以升至 MDG-5。[B1][B3][D7]

## 4. 趋势成分处置口径

**已将趋势读入档位。** AWS 增速连续加速、长期产能预订、自研硅与 AI 业务扩张，以及零售履约覆盖扩大，均按“正在增强”处理；自由现金流转负、资本强度上升、Q3 增速指引明显低于本季、客户集中度与零售留存缺口，则按“正在弱化或尚未证实”处理。[B1][B2][B3][B4][B6][B7]

净判断不是静态平均：增强端足以确认真实护城河并排除 MDG-2，弱化与缺口端却分属需求广度、价值捕获和用户自然粘性三个维度，因此把档位压在 MDG-3，而非用滞后收入与利润总量尚强去否定领先端风险。[A2][D1][D2][D3][D6]
