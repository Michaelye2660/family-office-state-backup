# 护城河评级卡 · MSFT（Microsoft Corporation）
**as-of 2026-07-30 · 依据 SWEEP-01 证据包 · 零工具一次成卷**

---

## 一、结论档位

**MDG-4 深沟**

- 很强的多层企业生态锁定，且已有观测级提价吸收实例；
- 未达 MDG-5 之由：①观测证据闸部分缺项——Copilot／M365 续订率与流失率零披露（D2），留存端机制证据缺位；②已观测之提价吸收（E7）**依赖捆绑机制**，按反事实纪律不得全额记为自然粘性（C1）；③席位端领先信号（+6%，增量偏低价值席）与收入端背离（D4）构成单一可识别长期威胁。
- **既有知识与证据包冲突处**：本席既有知识截止期早于 FY2026，包内 Azure 规模、Copilot 席位数等超出既有知识所及；属时序推进而非实质冲突，全部以证据包为准。

---

## 二、关键理由

1. **提价吸收有观测实例**：E7 高价套件推出两个月内数百家企业购数百万席位（EY 单笔 40 万席），系已观测之高档位被吸收，非纯前瞻推理（B3·领先）。
2. **开发者生态构成结构性迁移成本**：GitHub 2.25 亿用户、《财富》500 强逾 90% 使用、每三个 pull request 有一个涉及 agent——AI 工作流已嵌入开发底层（B2·领先／同步）。
3. **需求广度经剔除口径仍立**：商业 RPO 剔除 OpenAI 后 +25%，且环比 RPO 增量全部来自前沿模型公司以外客户，非单一大客户依赖（B6·滞后，辅证）。
4. **单一盯防威胁明确**：M365 商用付费席位仅 +6% 且增量主要来自中小企业与一线员工，收入 +19% 由 ARPU 升档与确认时点效应维持——量价背离，席位基盘趋饱的领先信号不得被滞后总量之稳所掩（B1／B3／D4·领先 vs 滞后）。
5. **MDG-5 硬闸缺项**：Copilot 留存端读数缺（D2）、capex 维持／扩张拆分缺（D1）、捆绑反事实未解（C1）——观测证据链在留存与去捆绑两环断裂，封顶于 4（D·缺口清单）。

---

## 三、可证伪条件

### 降级信号（亮起任一即复核降档，指向 MDG-3）
- **席位端**：M365 商用付费席位同比连续两季 ≤ +3% 或转负，且 ARPU 增速同步回落（量价双弱，B1／B3 引擎双熄）。
- **留存端**：首次披露之 Copilot 续订率／席位净留存显著低位，或 Copilot 净新增付费席位环比连续两季下降（B1）。
- **需求集中度**：剔 OpenAI 之商业 RPO 同比增速跌破 +10%，或披露显示前沿模型公司占 RPO 比重环比继续上升（B6／C2）。
- **开发者迁移**：GitHub 用户数环比转降、agent PR 渗透率逆转，或出现可观测之开发者净迁移披露／第三方调查（B2）。
- **盈利质量**：类本季 +$0.27 EPS 之一次性项目连续两季重现并支撑指引达成（A3）。
- **升档引擎停滞**：连续两季 E7 席位进展不再披露或披露显示环比不增（B3）。

### 对称升档条件（齐备即复核升档，指向 MDG-5）
- 披露 Copilot／M365 **实测续订率与流失率**且处高位——观测证据闸留存环补齐（补 D2）。
- **去捆绑证据**：独立（非 E5／E7 打包）SKU 之采用与提价吸收直接读数（解 C1）。
- capex 维持 vs 扩张拆分与单位算力成本下行曲线披露，证实基础设施规模优势为结构性（补 B7／D1）。

## 四、趋势成分处置口径

**已读入，双向对冲处理**：
- **增强侧**（领先端）：Copilot 净新增环比翻倍、GitHub Copilot 收入环比加速 60%＋、E7 两月快速采用、数据中心产能上线提速（B1／B2／B3／B5）——此增强趋势是本卡不落 MDG-3 的依据；
- **弱化侧**（领先端）：席位 +6% 且增量结构偏低价值席，提示传统席位基盘接近饱和；RPO 高增之表观数含 OpenAI 承诺，剔除后腰斩以上（B1／B6／C2）——此弱化信号是本卡不升 MDG-5 的依据之一；
- **纪律执行**：未以「收入 +18%、RPO +84%」等滞后总量否定席位端领先侵蚀；亦未以席位放缓否定价值捕获转移之实证。趋势净读数：**河道在拓深，但拓深引擎（捆绑升档）之可持续性未经去捆绑检验**——恰为 MDG-4 之形。
