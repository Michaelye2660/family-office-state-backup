# 护城河评级卡 · AMZN（Amazon.com, Inc.）

**评级基期**：Q2 FY2026（期末 2026-06-30）证据包 · 2026-07-31
**知识冲突申明**：证据包所载 2026 年数据超出本席既有知识时点，全程以证据包为准；员工数两源不一致处依包内纪律取一手值 1,595,000（A4/D5）。

## 一 · 结论档位

**MDG-4 深沟**

- 未予 MDG-5 之由：观测证据闸虽有已观测机制证据（B1 积压与产能预订系已发生之需求侧承诺，非纯前瞻），但存在**单一可识别长期威胁——对 AI 超级周期之依赖**（客户集中度未知 D1 ＋ 现金流转负 B6/D2 ＋ 指引减速 B7/D3，系同一威胁之三面），且零售侧领先端读数全缺（D6），不足以支撑「几乎不可能失守」。

## 二 · 关键理由

1. AWS 积压 $496B 同比三位数增长、2027 年大部分与 2028 年相当部分产能**已被客户预订**——此系已观测之需求侧承诺（切换成本＋容量锁定），非前瞻推理。〔B1·领先〕
2. AWS 同比 +36.7% 系连续第五个季度加速、18 个季度最快，且自研芯片运行率逾 $25B、获两大 AI 实验室多年多吉瓦承诺——纵向整合正在加深价值捕获。〔B2/B3·同步＋领先〕
3. AWS 以 21% 收入占比贡献 60.4% 营业利润（39.3% 分部利润率），显示定价权与规模成本优势已兑现为利润结构，惟 +650bp 中约 130bp 系衍生品会计收益须剔除。〔A2/B5·同步〕
4. 单一长期威胁明确：TTM FCF 由 +$18.2B 转 **−$7.6B**、capex 指引上调至 $220B、Q3 指引骤降至 +9%～+12%、积压之 AI 实验室集中度**无任何披露**——护城河深度真实，但其近期扩张系押注 AI 需求持续性之单向下注。〔B6/B7/D1/D2/D3·滞后＋领先并存〕
5. 零售侧「低 14%」系管理层转述第三方（Profitero），非公司自身实测；Prime 会员数、续订率、流失率零披露——零售护城河之领先端主张缺乏可核机制证据，仅能以滞后总量（北美 +16%）旁证，依纪律不得加权。〔B4/D6·同步（且证据等级降档）〕

## 三 · 可证伪条件

**降级信号（任一亮起 → 复评，倾向降至 MDG-3）**：
1. 后续披露显示 Anthropic＋OpenAI 合计占 AWS 积压 **>40%**，或任一家公开宣布主力算力迁移至他云／自建。
2. AWS 收入同比增速**连续两季**回落且落至 +25% 以下，同时 capex 指引不降（需求减速＋供给刚性剪刀差）。
3. TTM FCF **连续四季**为负且 2027 capex 指引再上调至 $260B 以上。
4. Q3 FY2026 实际净销售额低于指引下限 $197.0B（证实减速系真实需求转弱而非保守惯例，即 C3 之 (c) 项落地）。
5. AWS 积压总额环比转降，或「产能预订」表述在后续电话会中消失／弱化。

**升档信号（同时满足 → 复评，可议 MDG-5）**：
1. 积压集中度获披露且两大 AI 实验室合计 **<30%**，证实需求广度（补 D1 缺口）。
2. 出现公司自身披露之**提价被吸收实例**或 Prime 续订率／流失率实测读数且稳定（补观测证据闸与 D6）。
3. TTM FCF 回正，且剔除一次性与利用率因素后 AWS 结构性 margin 仍提升（补 C2/C4）。

## 四 · 趋势成分处置口径

**已读入，双向对冲后净读为「中性偏增强、但打折」**：AWS 加速五季（B2）与积压三位数增长（B1）系增强信号，已计入维持 MDG-4 上沿；但 Q3 指引减速（B7）、FCF 转负（B6）与集中度黑箱（D1）系同一威胁之弱化端张力，**故增强趋势不足以推升至 MDG-5**——依观测证据闸，需求广度与提价吸收之实测证据到手前，增强成分只抵消弱化疑虑，不产生升档动能。另依时序纪律：北美／国际收入总量之稳健（滞后）**未被用于**否定零售领先端读数缺失（D6）之扣分。
