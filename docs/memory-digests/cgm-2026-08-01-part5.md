## 二 · 🔴 本场次之实：**我比对的不是「我们打算发什么」，是「两席各自收到了哪一串字节」**

G4 的交接书把起跑命令写得很完整，照着跑一行就完事。**但那条命令喂给 Fable 席的是证据包原文，而 GPT 席收到的是中转仓里那份外发正本。** 这两个文件不是同一个。

于是起跑前我把两串实收字节拿来逐字比：**差 13 行。** 其中一处是实质——证据包**原文末行**：

```
——证据包构建：[执行侧·CGM]（claude-opus-5·A 类机械·零判断零建议），2026-08-01·SGT
```

**这一行在外发正本里已经依 `ADJ-0801-03①` 剔掉了（残留实测 0，封存清单里逐行记着）；而 runner 读的是原文，所以它原本会跟着 payload 进 Fable 席。**

`-03①` 立这条规则的理由逐字是：「把**我方用什么模型**外发给持权外部席，本身即是喂给对方一条破盲线索；其危害与『两席互不见』所防者同类，**只是入口不同**。」

**——而这就是另一个入口。**

### 何以这一条值得记

1. **一个只在一条路上执行的剔除规则，等于没有规则。**
2. **更硬的一层**：它造成两席输入不对称，**而外发正本的包头正自陈「两席收到同一份内容」**。
   **包头的申报与实况不符，可当时三项机械自核全过** —— 因为**机械核测的是「外发正本剔了什么」，测不到「另一条路有没有走同一套规则」**。
   这正是 G4 交接书 §五-4 那句「机械核测得出剔了什么，测不出有没有在建包时就守住」的**同一形态、另一个入口**。
3. **它不是靠想到的。** 我没有「怀疑 G4 的命令」这个念头；我只是**把两边实际收到的东西各算了一次 sha1**。
   **推理用来提问，凭据用来回答** —— 这条是 G4 在 `cgm-2026-07-31.md` §五-3 写给下任的，本场次是它的第一次兑现。

## 三 · 我做了什么，以及我不确定我有没有权做

**做了**：把 `-03①` 的**既有**剔除规则补执行到 Fable 路径。判据预先写死在 runner 卷头（**仅二类**）、被剔行**逐字印出**（本轮命中 1 行）、**证据实体剔除数 0**、剔除申报落回执**不落 payload**（设盲通则：**在盲性场景下，指涉即泄漏**）、**不另造第二个 runner**。

**没做，也不该我做**：剔除后残余的 11 行（外发正本的包头元数据块）**去留，我不择一**。
两个方向都有代价——**补上包头，Fable 席当场就知道「自己是两席之一、另一席是 GPT、产出会被比对」，那是真实的实验污染**；不补，则包头那句「同源同包」得改写成「证据与问法同源，实验元数据不同源」，否则它不成立。**属判断类，呈 GM。**

**🔴 而我自己的定性也呈了**：我判这是「执行一条在效的裁定」而非新设计，所以**先办了、后呈**。若 GM 判它属改盲设计，一字即回，本卡作废重造。
**我把没先呈的那个权衡也写上去了**：`-03①` 判据无裁量空间，而先呈则本轮起跑落空、委托人「可启动」之令当轮无产出。**这个权衡是我做的，不是规则替我做的。**

## 四 · 一处「候」字的真实含义被实测改写

交接书把 GPT 席记作「候该席自行 commit 答卷」。**我 clone 了中转仓实看：tip 仍是 `3c2067a`（就是投放那一笔），`reports/` 里没有任何 `SWEEP-SPGI` 件。**
