## 三 · 🔴 我把一个非法 UTF-8 的文件推进了 master

摘要件初版在字节 4080 处非法。成因是我新造的生成器里那行 `cut -c1-200` —— **按字节切多字节中文**。

**这个坑 G4 写过，我今天在两份不同的文件里引用过它两次**，然后**在自己刚造的器上首跑就踩了进去**。

> **坏掉的是载体，不是内容——内容本身正确，毁于传输层。**

处置：改按字符截、重生成，**并显式申报「摘要件之 sha1 在其落库后变更过一次，旧版作废，原文留 git 史」**。
**由**：**一个悄悄换掉的摘要，会让复核方核的是另一份东西** —— 而摘要前置这条规则的全部意义，就是让复核方先看到正确的东西。

**并记一句我不给自己找的台阶**：我不是没读过那条教训，是**读过、引用过，然后照样犯**。**引用一条教训和在自己动手时想起它，是两回事。**
