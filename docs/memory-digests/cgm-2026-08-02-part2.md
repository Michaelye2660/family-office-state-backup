## 三 · 🔴 我被自己写的闸咬住一次（本段第二值得记）

`gen-gm-snapshot.sh` 内上限**原定 6,144 B** —— 建器时的预估，**n＝0，无任何实测依据**。
**首跑实测 7,336 B，闸当场咬、报 🔴 且未截断。所拦者就是这个器的作者本人。**

依实测重标定 8,192 B。**因为我正是受益方，所以得把自辩写下来**：

> **拆闸 ＝ 放宽以让自己通过；标定 ＝ 用实测替换一个无依据的预估。二者之别在有无新证据。**

四个值（原值／咬合／实测／新值）同书器头，`fail-closed` 行为一字未动。
**惟仍如实标：一个作者调高自己被卡住的那个上限，其可信度不由他的理由决定，由留痕决定。**

**并自捕一处、落库前修**：重标定后**产出件件头仍印旧值 6,144** —— **器改了而输出没改，每跑一次就再散播一次旧值**（part6 §四之二「取代注写在文件头，而尺是给读输出的人看的」同型）。
