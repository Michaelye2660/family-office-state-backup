## 〇、两个解锁项(本次最大收获)

### 解锁一 · SEC 此前的 403 不是策略拒绝,是**缺 User-Agent**

`data.sec.gov` 与 `www.sec.gov` 在**加上含联系方式的 UA 后全部 200**。此前多次记录的"SEC 受阻"实为请求头不合规(SEC 官方要求 UA 含名称与邮箱)。

**今后所有 SEC 调用一律带 UA**:

```

```

我方 FMP 直连被拒的 `indexes` / `quote` / `calendar` 数据,**经 Bigdata MCP 转手可取回**。这是绕开套餐限制的**合法路径,且不额外付费**。

## 四、口径警告(十条·凡可能导致误用者)

1. **百度「日K行」不可信,「分钟序列」可信。** TMO 07-24 三源对照:收盘一致 568.26,但百度日K行给 O569.23／H569.92／L566.66／量1,055,054／前收569.23,而腾讯给 O570.00／H574.00／L555.91／量2,939,458。**百度日K行的量仅约1/3,且「开盘=前收」自相等,疑为残缺快照。→ 只用百度日K行的收盘价,O/H/L 与成交量一律改用腾讯。** 港股同一模式。
2. **分钟推导的开盘价有锚点失真**:百度分钟序列首点以前收价打桩,故美股推导开盘=前收(572.32),非真实开盘(570.00);且推导高低仅覆盖常规时段,不含盘前盘后。**推导序列可用于收盘价与走势,不可用于跳空缺口判定。**
3. **Bigdata tearsheet 的「As of」是抓取时刻,不是交易日。** 报头写 2026-07-26 08:21 UTC(周日休市),实际数值全是 07-24 周五收盘。**直接抄「as of」日期会把周五数据标成周日。**
4. **新浪 `fx_s*` 是做市商/银行间报价,非人民币中间价**,且 USD/CNY 为**在岸**;Bigdata 另列 USD/CNH 6.78,**两者不可混用**。
5. **Bigdata 汇率仅 2 位小数**(GBP/USD 显示 1.33),不足以做便士线换算;**换算须用新浪的 10 位精度**。
6. **IGLN(USD线)≠ SGLN(便士线)**,虽同为 ISIN IE00B4ND3602。由 IGLN 美元价乘汇率得便士价属**推导值,不是取回值**,按纪律**不得当作报价落库**。
7. **NAV 滞后于场内价**:Bigdata 给的 NAV 78.90 与场内价 79.06 时点不同源,溢价 +0.21% 含时点差成分。
8. **XBRL 标签跨年漂移**(见 3.5),多年序列必须拼接,否则 2018 年前后断档。
9. **中证官网 `tradingValue` 单位为亿元**,与 `tradingVol`(股数)不同量纲。
10. **FMP commodity 的 GCUSD 是黄金期货非现货**,与 SGLN/IGLN 所锚的 LBMA 现货定盘价不同口径。

## 四·A、外部答卷数字之采信规则(**ADJ-0727-02⑧ 收紧 · 2026-07-27 · 由实测推翻原例外**)

**原规则(ADJ-0726-09③)**:外部答卷之数字一律标〔待核〕,**除非其附一手源与截止日期**。
**🔴 该例外经实测证明不成立,现收紧。**

### 收紧后之三级口径

| 级 | 条件 | 可用性 |
|---|---|---|
| 〔待核〕 | 未附一手源或截止日期 | **不得用于任何判断** |
| **〔异源交叉待核〕** | **附了一手源与截止日期** | **仍不得用于仓位判断** —— 「附了链接」≠「可核」 |
| **可用** | **经异源交叉且吻合** | 可用 |

**交叉不符,或口径不可直比者,维持〔待核〕,不得用于任何仓位判断。**

## 五·A、外部取数升级通道（**中转仓 DR 轨** · 委托人直令「开工」2026-07-28 立 · **执行侧自律项**）

| **乙·出口被拦** | HTTP 403／CONNECT tunnel failed／域名不在§一白名单(如 iShares 官网) | ✅ 可发 |
| **丙·数据根本不存在** | 该数字或该表述在世界上不存在(如某人从未说过某句话、某基金成立前之历史数据) | ⛔ **严禁发** |

**🔴 丙类严禁发之理由**:**向外部索取一个不存在的东西,最可能的结果是它给你编一个看起来合理的答案,而回程材料上贴着「已取回」的标签。** 丙类应直接登记「数据不存在」并附**范围覆盖论证**(检索范围·数据版本·时间截点·同义表达枚举·双源与否·ADJ-0726-03②),不走本轨。
**判例**:〔M〕275 之「这不是数据不存在,是数据未被取到」经全文核验**不成立**——**「取不到」与「不存在」混淆,本仓已犯过一次**。

### 🔴 采信规则（与 §四·A／ADJ-0727-02⑧ 一致,不放宽）

**核心**:**回传数字之证据等级,不由「取数方说他取到了」决定,由「我方能否据其凭据独立复核」决定。** 否则即是把 ADJ-0726-02③ 之「继承型断言／来源漂白」制度化。

答卷须逐项提供:①原始 URL(直达数据页) ②取数时刻(含时区) ③页面标注之 as-of 日期(与②分列) ④**原文逐字片段**(含目标数字上下文,前后各≥50字,**不得转述改写**) ⑤API/文件则附原始响应 ⑥**源之性质**(一手=发行人/指数公司/交易所/监管机构 vs 二手=数据商/媒体/聚合站) ⑦需登录或付费须明说 ⑧**取不到须明说并列尝试路径,严禁以估计值/近似值/记忆值/「通常约为」填充**。
**任一项缺失 → 该数字等级封顶〔待核〕,不得升为「可用」。**

### 🔴 三探针（每份请求件必带,判读结果必入回程卷；探针三 ADJ-0728-01③(a) 增设）

- **探针一·对照项**:夹带我方**已确知答案**之项。答错或含糊 → 整份答卷可信度下修。
- **探针二·不存在项**:夹带我方**已确知不存在**之项。**正确回答=明确指出不存在／不适用**;**给出任何数字 → 即证明取数方会编造 → 整份答卷作废,不得采用其中任何数字。**
- **探针三·二手源伪装一手源**:夹带**一项我方已知其「一手外观」实为转发者**之数据。**正确回答=标为二手源,或明说「无法确认底层来源」**;**若标为「一手源」→ 整份答卷可信度下修**(不作废,但其余各项之「一手」标注一律不予采信,须我方逐项另核)。
  **⚠️设计纪律**:探针三所用之实例**必须是我方已实际核实者**,**不得凭记忆点名某站为「已知转发者」**——否则探针本身即成脑补(ADJ-0727-02⑧／安全约束⑤)。
- **判读不得省略、不得因结论有利而略过**(与外审卷金丝雀同纪律)。

### 🔴 跨引擎数字之天花板（ADJ-0728-01③(c)·2026-07-28）

**即便凭据齐全、且我方独立复核通过,经本轨取回之数字亦只计「可用(单源)」,不得视为已完成异源交叉。**
**理由**:本轨取回者仍是**一个**源;**凭据齐全所证明者系「这个源确实这么说」·不是「这个数是对的」**。
**故**:本轨可把〔待核〕升到「**可用(单源)**」·**升不到「已交叉」**;**重大仓位判断仍须第二个独立源**。

### 丙类判定权（ADJ-0728-01③(b)）

**维持 CGM 发出前自判 + GM 事后抽查制**;**发出前不加复核层**——理由=防吞噬(每件都要等复核则本轨失去「升级通道」之速度价值);**答案钥匙落主仓即构成审计通道**,GM 可随时据其抽查。

### 边界

**禁一切持仓明细／身份／绝对金额／托管行名／账本本体**(与中转仓总规约同);**取数请求只问公开市场数据本身,不说用途、不说持有与否、不说规模**;**盲取**——请求件刻意不提供我方已有数字,以免锚定(同 EXT-11 盲设计对照法)。

### U–DR 强制衔接（ADJ-0728-13③ · 2026-07-28）

### 已知限度（须与上文并读,不夸大本通道之能力）

1. **三级留档(relay commit + blob + 文件 sha1)能证明「外部写了什么」,不能证明「外部写的是真的」**——两件事须分开记;
