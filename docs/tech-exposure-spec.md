## 二·A、🔴 本口径之一处性质（**须明说，否则将来必被误读**）

**本口径下之「月度读数」系「满配后推算」，不是当期实际敞口。**

理由：§一第 7 项把**嵌入部分固定按 38% 基准**计算（IWDA 满配中枢），而**非**按 IWDA 当期实际权重（现约 1.2% NAV）。故：

| | 读数 | 性质 |
|---|---|---|
| **本口径之月度读数** | **≈ 24.99%** | **满配后推算** —— 嵌入部分按 38% 固定 |
| 当期实际总科技敞口 | **≈ 10.5%** | 嵌入按 IWDA 实际 1.2% 算（〔M〕341⑤ 对照值） |

**两条推论，皆须并读**：
1. **月度读数近乎静态** —— 它**不随 IWDA 建仓进度移动**，只有**口袋科技持仓变化**或 **IWDA 自身行业权重变化**时才移动。故「每月比对」实际上是在监测这两者，不是在监测建仓进度。
2. **月度读数与当期实际敞口相差约 14.5pp** —— **报读数时须标明系哪一个**；把 24.99% 当作「我们现在有 25% 的科技敞口」是错读。
