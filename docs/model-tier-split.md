# 模型档位分工清单（日常 Opus ／ 判断 Fable · 2026-07-28 · 呈委托人）

> **分界原则（一条）**：**结果能否被机械抓错**——脚本、预登记判据、sha1/四验、上级复核任一能拦住错误的 → Opus（甚至 Haiku）；**错了会静默存活的判断 → Fable**。
> **设计目标**：Opus 档**永不产出判断类**，从源头杜绝「标临时→积压→复裁窗清账」——2026-07-28 全天复裁窗即前车之鉴：**降档三天省下的额度，清账一天全还了回去**。

## C · 升级触发线（Opus 跑到这里必须停手升档,不得强行判）

- 触发器由未触发→**已触发**;红线**触及或迫近**;任何**亮灯**或 H 类疑似;
- 四字段校验**失败**之后的处置（机械核 Opus 可做;**放不放行系判断**）;
- DR 探针失败,或两侧数据**显著不吻合**;
- 发现台账矛盾/条文冲突;
- **任何要写出「建议/倾向/判定」字样的段落**。
