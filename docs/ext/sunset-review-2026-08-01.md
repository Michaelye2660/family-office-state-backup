## 三 · 答钩之第二问：**三线是否已固化为制度增生？**

**裁：并存之实况与钩所设想者不同——不是「三条都在跑而冗余」，是「一条在跑、一条跑过一次即停、一条从未跑过」。**

| 线 | 13 日窗内之实况 | 属「增生」否 |
|---|---|---|
| 线3 中转仓 | 34／46／27 —— **在跑** | 否 |
| 线1 API 硬净室 | **跑过 1 次真金（07-20），其后 13 日零往返**；现「已解锁·未启用」 | **否——但理由不是「它在用」** |
| 线2 EXT-R | **零往返·入席登记 0 件**；首审 2026-08 底**未到** | **否——但理由是「还没到该用的时候」** |

**🔴 故本轮之结论是一句更难看、也更有用的话**：
> **这三条线不是冗余，是两条闲置。而「闲置」与「冗余」的治法完全相反**——
> **冗余该废其一；闲置该问的是「它到底会不会被用」，而不是趁它没动手先把它砍了。**

**本轮不废任何一线**（**最保守之一侧**）。理由逐条：

- **线1 不废**：`ADJ-0719-13(3)` 明定**真金 T1–T4 守 API 硬净室、不走中转仓**；**废之即真金无合规载体**。其 13 日零往返之成因**已知且非闲置本身**——07-20 后无真金动作，且 08-01 起状态为「已解锁·未启用」（委托人令）。**「没有真金要送」不是管道的问题。**
- **线2 不废**：其**首审时点（2026-08 底 R3）尚未到**。**在一条线有机会运行之前就宣判它没用，是拿「我还没让它跑」当「它跑不起来」的证据**——此系本仓已反复申斥之形态。

**🔴 但「不废」不等于「不管」——照「凡新增结构，立时即写其死法」，本轮给两条闲置线各写死一个再评点**（**到期自曝，不靠人记得**）：

## 四 · 答 JG-19：立制五项（**依 `adjudication-lanes.md` 规则一「缺省 CGM 单边」定·五项皆不在必上门清单内**）

| # | 项 | **裁** | 依据与其强度（**如实标**） |
|---|---|---|---|
| **立-1** | 批次周期 | **月度一批** | 与**季度**授权范围探针、**月度**抽验错开；**依据＝既有节拍，非最优推导** |
| **立-2** | 单批件数上限 | **5 件** | **🔴 n＝0 之阈值，如实申报**：本仓**唯一实跑过的批量是 SWEEP-01 之 5 件**，故取 5 —— **它是本仓有运行基础的唯一数字，不是推导出的最优值**。照〔M〕468⑩「**n＝1 之阈值与它所要治的拍脑袋的数同类**」，**其死法一并写死**（见下） |
| **立-3** | 触发 | **到点且有料方发**（防空转）；**零件亦须出一行「本批 0 件」** | **静默＝不可分辨「无料」与「忘了」** |
| **立-4** | 材料边界 | **沿用 `ADJ-0719-12④`，不另立** | %／权重／倍数**放行**；**绝对金额·身份·托管行拒发**。**不另立即不新增失效面** |
| **立-5** | 分工载于何处 | **并入 `docs/ext/audit-governance-charter.md` §三，不新建档** | 依 `JG-9`「**实质已由既有件覆盖，再立＝制度增生**」——**本件正在复议增生，不宜自己先造一个** |

**🔴 立-2 之死法（立时即写·不待其出事）**：
**首两批跑毕即强制重标定**——须以两批实测（件数／往返耗时／检查器命中／委托人转发次数）**重定或确认该数，并同书两批读数**；
**重标定前，5 件系上限不是目标**；**逾期未重标定即入周对账 🔴**。
**理由**：**一个 n＝0 的数，若不写死它何时必须被换掉，它会因为「一直没出事」而变成永久值**。
