## 总结结论

真正的“标的身份盲”既然不可得，就不应继续把匿名化强度当作实验有效性的主要来源。更可行的路线是把控制目标从“评审者不知道是谁”改为以下四件事：

1. **不知道哪一项材料变化是实验干预，且不知道研究者期待哪个方向**；
2. **不知道用于事后结算的结果或隐藏评分键**；
3. **在看见结果之前，评分规则、排除规则、成功标准已经锁定**；
4. **每一个判断都能追溯到被允许使用的证据，而非只看最终结论是否碰巧正确**。

因此，本实验最多可以分层回答三种不同问题：

- **过程有效性**：评审者是否真的按尺子读数，而非仅凭身份先验作答；
- **内部构念有效性**：与护城河机制相关的证据发生预先指定的变化时，尺子是否按正确方向、正确幅度响应，并对无关变化保持稳定；
- **外部效度或预测效度**：尺子的读数是否对尚未发生、且未被评分材料使用的独立结果具有解释力。

单一、可识别的历史案例，即使答“对”，也不能独立证明第三层。它可以用于证伪、压力测试和过程审计，但不应被包装成对整把尺子有效性的确认性验证。

# (a) 控制设计

## 一、先改变实验单位：不再把“公司身份”当作随机化对象

真正可随机化、可隐藏的对象应当是：

- 证据包中的某项机制证据是否被增强、削弱、删除或替换；
- 哪位评审者先看到哪个版本；
- 哪些变化属于计分干预，哪些只是安慰剂变化；
- 哪些评分维度被完整提供，哪些维度被有意制造缺失；
- 哪些结果被留作事后结算。

也就是说，实验应从“匿名公司猜评级”改造成“同一身份指纹下的受控证据干预实验”。身份可以被识别，但身份在各版本之间保持不变；若评分仍随机制证据发生预注册方向的变化，则该变化不能仅由身份识别解释。

## 二、建议采用的最小可行架构

在评审席位有限的情况下，可采用以下三角色结构：

- **材料构造者**：依据预注册的干预表生成证据包，不参与评分；
- **两个独立评分席**：在彼此隔离的会话中评分，不交流，不看对方答案；
- **协议审计者**：检查证据引用、规则执行和机械结算，不重新判断标的优劣。若席位极少，审计者可由事后脚本加一次独立审计会话承担。

建议至少构造四类任务，每类包含多个平衡版本：

1. **机制相关干预对**：只改变一个预先指定的护城河机制证据；
2. **安慰剂干预对**：只改变按尺子不应影响档位的信息；
3. **缺失或冲突证据对**：删除关键证据，或加入同轴冲突证据；
4. **时间切片或退化阶梯**：保持身份不变，按预注册顺序逐步加入弱化信号。

两个评分席采用平衡不完全区组或拉丁方分配：同一干预对的 A、B 版本由不同席位先看到，跨任务交换版本方向，以抵消“某一席位天生更严或更松”的偏差。若同一席位必须看两个版本，应在中间插入无关任务、改变排版并随机顺序，同时把记忆污染列为已知限制。

## 三、具体控制及其封堵的失效模式

| 控制手段 | 具体做法 | 主要封堵的失效模式 |
|---|---|---|
| 1. 预注册评分合同 | 在任何评分前锁定尺子版本、轴定义、档位映射、无法评级条件、置信度规则、降级触发器、主要与次要终点、排除规则、成功阈值和分析脚本。之后不得因结果不好而改阈值。 | 事后改尺、移动门槛、挑选有利终点、可选停止、结果出来后重新解释条款。 |
| 2. 先验基线记录 | 在评审者看到实验材料前，先要求其记录：可能识别出的标的、身份置信度、仅凭既有知识会给出的初始档位、关键先验理由。该答案封存，不能回改。 | 将身份先验伪装成尺子读数；无法区分“材料带来的更新”与“原本就知道答案”。 |
| 3. 身份识别显式测量 | 每个证据包评分后再次报告身份猜测、识别置信度、是否想起材料外事实、是否猜到实验干预。身份识别不作为违规，而作为协变量和污染指标。 | 假装盲成功；把高识别组与低识别组混在一起；遗漏干预识别和需求特征。 |
| 4. 闭卷与开卷双臂 | 闭卷臂只准使用包内编号证据；开卷臂允许补充公开信息，但必须逐条列明来源和新增事实。先做闭卷，再做开卷，结果分开报告。 | 将“材料不够”误判为“尺子不好”；或将“依赖外部常识”误判为“尺子自己有效”。 |
| 5. 逐项证据溯源 | 每个轴的读数必须引用证据条目 ID，并分成“观察事实—中间推断—档位结论”三栏。关键结论若无允许证据支持，计为未落地，不因最终档位碰巧正确而得分。 | 凭身份、常识或既知结论倒推后，再用尺子语言进行事后包装；所谓“rubric laundering”。 |
| 6. 机制相关反事实对 | 对同一身份指纹构造两个总体同样逼真的版本，只改变一个机制变量，例如转换成本证据、跨边网络效应、资本开支性质、监管可替代性或生态多归属情况。预先写明应当上调、下调或仅降置信度。 | 身份先验支配一切；尺子对其宣称测量的机制不敏感；评审者只复述公司名对应的固定结论。 |
| 7. 安慰剂变化 | 改变版式、叙述顺序、无关规模数字、非评分时间点或不应进入该轴的信息，并预注册“档位不应变化”。 | 对显眼数字、篇幅、措辞、顺序或格式过度反应；将一般显著性误当作护城河证据。 |
| 8. 证据删除与冲突测试 | 删除一个决定性证据、降低其可信度，或加入同轴反向证据。预注册期望行为：置信度下降、档位收缩或转为“无法评级”，而不是机械维持高置信。 | 强迫给档、忽视缺失、虚假精确、对证据质量不敏感。 |
| 9. 时间切片设计 | 对同一可识别对象构造多个“截至某时点”的材料包，身份保持不变，只允许使用当时可见信息。评分顺序随机，后续结果不进入评分包。 | 把身份变化与证据变化混淆；无法检测尺子能否识别逐步弱化；但历史后见之明仍需另行控制。 |
| 10. 结局盲或未来留出 | 用于最终验证的结果变量、后续事件或人工隐藏评分键不向评分席开放。最强版本是前瞻性留出：先封存评分和触发器，待未来窗口结束后结算。 | 评审者已知结局后倒推；材料构造者用结果污染输入；历史案例中的后见偏差。 |
| 11. 尺子臂对基线臂 | 设置至少一个对照：身份加一般判断提示、无尺子的自由分析、缩减版尺子或通用清单。采用独立席位或严格平衡的交叉设计。 | 评审者本来就会答；正确来自领域常识而非尺子的增量价值。 |
| 12. 隐藏的评分键 | 干预方向、安慰剂项目、主要终点及关键对照的标签只由材料构造者或审计者持有；评分席只知道需要独立读数，不知道研究者期待哪一版更高或更低。 | 需求特征；迎合研究者；识别“这是低档对照”后配合给低。 |
| 13. 会话与席位隔离 | 每席独立上下文，不读其他评审文件，不共享中间答案；统一使用冻结提示、相同信息预算和固定澄清 FAQ。所有提交带时间戳并一次性封存。 | 多席互相污染；设计者通过追问暗示答案；后提交者吸收先提交者结论。 |
| 14. 有效样本量按家族聚类 | 同一模型家族的多个席位不得被当作完全独立样本。统计时按模型家族或基础模型聚类；报告原始席位数和有效独立簇数。 | 用多个高度相关的同源回答制造虚假重复性和过窄不确定区间。 |
| 15. 顺序和版本平衡 | 随机化包顺序、A/B 标签、叙述格式和评审先后；在不同席位间反向分配。 | 锚定、疲劳、首因效应、最近效应、固定版本与固定席位混淆。 |
| 16. 合成机制锚点 | 另设少量完全虚构或复合的微型案例，只呈现尺子定义所需的机制原语，并由预注册规则给出方向键。锚点只用于检验规则一致性，不宣称代表现实公司。 | 现实身份知识完全压过规则；无法知道评审者是否理解尺子条款。 |
| 17. 干预合理性审计 | 在评分前由不参与评分的审计者检查每个 A/B 版本：除目标机制外，其余关键事实是否等价；版本是否在经营逻辑上自洽；是否存在明显答案提示。 | 反事实包不真实、一次改了多个变量、版本可被轻易识别、所谓效果其实来自材料质量差异。 |
| 18. 机械化协议违规判定 | 预先规定哪些行为导致该条目无效：引用截止日后的事实、使用未授权外部信息、漏答必填轴、关键结论无证据 ID、修改已封存答案等。 | 事后为有利结果放宽规则；将不合规答案纳入成功统计。 |
| 19. 稳健性复测 | 对一部分材料改变提示表述、上下文长度或随机种子后重复评分；把模型版本、日期、温度等运行条件记录在案。 | 结论只在某个提示措辞或一次随机采样下成立；平台版本漂移被误认为尺子变化。 |
| 20. 失败优先报告 | 预注册必须公开的失败项目，包括反方向移动、安慰剂误动、高置信无证据、席位分歧和无法评级比例，不允许只展示成功示例。 | 樱桃挑选、只展示好看的个案、把异质性藏在平均数后。 |

## 四、最值得优先执行的四个控制

若资源非常有限，应优先保留：

1. **先验基线记录**；
2. **机制相关反事实对加安慰剂对**；
3. **逐项证据溯源**；
4. **尺子臂对无尺子基线臂**。

这四项共同回答最关键的问题：评审者是否因材料中的机制证据而改变读数、是否对无关变化保持稳定、是否能展示条款到结论的可审计路径，以及尺子是否比“本来就知道”带来增量。

# (b) 失效模式清单

下面按实验链条列出“看起来成功但实际无效”的主要方式。

## 1. 先验与身份污染

- 评审者识别标的后，直接复述既有看法；
- 评审者记得市场共识、历史结局或著名争议，再倒推档位；
- 评审者先有结论，之后只挑能支持该结论的尺子条款；
- 评审者从特征组合猜出研究者想要的“高”或“低”；
- 评审者在训练数据、既往对话或其他评审中见过相同案例；
- 多个同模型家族席位共享相似训练语料和先验，形成相关错误；
- 席位之间直接或间接共享答案，造成伪一致性。

**匿名化无法彻底封堵的部分**：训练语料中的案例记忆、领域共同先验、同模型家族的相关先验、对历史结局的记忆，以及凭经营指纹恢复身份。匿名化最多降低显式提示，无法制造真正无知识状态。

## 2. 尺子并未产生增量

- 无尺子时也会给出同样结论；
- 评审者靠一般商业常识作答，再把答案翻译成尺子术语；
- 尺子只是增加解释长度，不增加方向准确性、区分力或可复核性；
- 尺子过于宽泛，任何结论都能找到条款自洽；
- 同一证据可被不同轴重复计算，造成任意放大；
- 评分者只使用其中一两个熟悉轴，其他轴成为装饰；
- “置信度”只是语言强度，不对应证据充分度或稳定性。

**匿名化无法封堵的部分**：一般常识替代、条款宽泛、事后合理化、重复计分和无增量价值。这些是尺子与执行流程的问题，不是身份泄露问题。

## 3. 材料包失真或不对称

- 为匿名而删掉了做出判断所必需的信息；
- 高档版本材料更完整、低档版本材料更零碎；
- 反事实版本一次改变多个机制变量，无法归因；
- 合成版本在经营逻辑上不可能，评审者只是在识别“坏写法”；
- 关键数据的时点、法域或口径被模糊后失去解释性；
- 材料篇幅、措辞强弱、数字精度、表格位置泄露实验条件；
- 正反证据的可信度等级不对称；
- 只挑支持研究者预期的证据，遗漏反例；
- 时间切片出现年代错配或使用了当时不可得的信息。

**匿名化无法封堵的部分**：证据选择偏差、材料构造者偏见、反事实不自洽和时间泄漏。匿名化甚至可能加剧材料失真。

## 4. 对照本身无效

- “应当被判低”的案例只是研究者主观认定，并无独立标准；
- 对照过于极端，任何一般常识都能答对；
- 对照与主案例在行业、时点、信息密度或证据质量上不匹配；
- 低档标签由后来发生的结果定义，评分材料却已包含结果线索；
- 合成低档案例把答案直接写进描述；
- 安慰剂变化实际上会影响某个轴，导致错误判罚；
- 负对照不逼真，无法代表真实使用场景。

**匿名化无法封堵的部分**：所谓“正确答案”缺乏独立性、对照选择偏差和基准循环。

## 5. 结果指标与真实构念循环

- 用尺子自己的条款来定义“正确评级”，再用同一条款验证尺子；
- 用评分材料中已经出现的经营指标作为事后结果；
- 将当前经营表现、公司规模或盈利水平误当作护城河牢固度；
- 将“护城河正在弱化”与“当前护城河已经低”混为一谈；
- 结果指标受管理决策、宏观环境或监管冲击影响，却被全部归因于护城河；
- 只看成功存活者，忽略失败或被收购样本；
- 选取已知结局的历史案例，形成后见偏差；
- 外部结果窗口过短，无法覆盖护城河概念宣称的持续期。

**匿名化无法封堵的部分**：构念定义不清、基准循环、结果内生性、后见偏差和时间窗不匹配。

## 6. 统计与结算失效

- 看到结果后更改主要终点或阈值；
- 试很多材料版本，只报告命中的；
- 反复增加席位，直到出现想要的一致性；
- 把同模型家族的多席当作独立样本；
- 用总体平均掩盖某些机制轴完全失效；
- 只看“方向正确”，不看反方向错误、安慰剂误动或幅度过大；
- 把平局、无法评级或缺失答案排除后提高成功率；
- 把高席间一致性误当作效度；
- 样本过小却作强确认性结论；
- 将多个来自同一基础案例的变体当作多个独立现实样本，造成伪重复。

**匿名化无法封堵的部分**：研究者自由度、伪重复、样本量不足和相关误差。

## 7. 执行与模型运行失效

- 提示词、上下文长度或工具权限在席位之间不一致；
- 一个席位获得额外澄清，另一个没有；
- 模型版本在实验期间更新；
- 随机采样造成一次性幸运答案；
- 上下文过长导致漏读某些轴；
- 顺序、疲劳或锚定影响后续读数；
- 语言转换改变条款含义；
- 评分席猜到自己正在看 A/B 干预，主动配合；
- 审计者在知道研究者期望后宽松判定协议合规。

**匿名化无法封堵的部分**：模型漂移、提示敏感性、审计偏见和运行条件差异。

## 8. 最危险的“伪成功”组合

最危险的结果不是明显失败，而是如下组合：

1. 标的被识别；
2. 评审者本来就知道主流结论；
3. 材料包只提供支持该结论的证据；
4. 评审者用尺子术语重述既有观点；
5. 多个同源模型给出高度一致答案；
6. 研究者以“一致且符合预期”为由宣布尺子有效。

这套链条可以产生非常漂亮、非常一致、解释也很丰富的结果，但几乎没有识别出尺子的独立贡献。

# (c) 可解读性判据

## 一、先规定允许宣称到哪一层

实验结果应按四道门结算，而不是只有“成功或失败”两个词。

### 门 0：协议完整性

只有满足以下条件，后续结果才进入结算：

- 尺子、材料版本、主要终点和阈值在评分前封存；
- 评分席未看到隐藏评分键和事后结果；
- 每份答案完成必填项并附证据 ID；
- 截止日后的事实、未授权外部事实和跨席信息没有进入闭卷答案；
- 所有排除均按预注册规则执行。

任何关键项失败，结论只能写为“协议失效”，不得继续宣称尺子通过。

### 门 1：机制敏感性与安慰剂稳定性

将五档序数映射为 1–5；“无法评级”不强行映射为中位数，而单独作为合法状态。对每个预注册干预对 \(j\)，记录预期方向 \(d_j\in\{-1,+1\}\)，以及两个版本的档位差 \(\Delta_j\)。

定义：

- **正确移动**：\(d_j\Delta_j>0\)；
- **不敏感**：\(\Delta_j=0\)；
- **反向移动**：\(d_j\Delta_j<0\)；
- **安慰剂误动**：安慰剂对出现非零档位变化，或出现预注册阈值以上的置信度变化；
- **缺失处理正确**：关键证据删除后，置信度下降达到预注册幅度、档位收缩，或转为“无法评级”。

建议在看数据前固定如下最低门槛；具体数字可按任务数量调整，但不得事后修改：

1. 机制相关干预中，至少 **75% 严格按预期方向移动**；
2. 反向移动不超过 **10%**；
3. 被定义为“重大机制变化”的干预，档位中位变化至少 **1 档**；
4. 安慰剂对至少 **90% 档位不变**；
5. 缺失或冲突证据任务中，至少 **75% 出现预注册的置信度下降、收缩或无法评级行为**；
6. 以上结果必须在至少两个隔离席位或两个独立运行簇中同向复现，不能只靠总体平均通过。

若通过门 1，只能宣称：“尺子对其声称测量的机制具有内部方向敏感性，并能区分相关变化与无关变化。”这仍不是外部效度证明。

### 门 2：相对无尺子基线的增量价值

为每个任务定义机械得分：

- 机制方向正确：+1；
- 平局：0；
- 反向：−1；
- 安慰剂不动：+1；
- 安慰剂误动：−1；
- 关键结论有合规证据链：+1；
- 关键结论无允许证据支持：−1；
- 在证据不足时正确使用“无法评级”或降低置信度：+1；
- 证据不足仍高置信强行给档：−1。

比较“尺子臂”与“无尺子或通用清单臂”的配对净得分。建议预注册：

- 尺子臂的平均配对净得分至少高出基线 **15 个百分点**；
- 该优势须同时出现在“机制方向”“安慰剂稳定”“证据落地”三个子项中的至少两个；
- 尺子臂不得通过显著增加“无法评级”比例来虚假提高准确率，除非材料确实属于预注册的不充分条件；
- 若任务量足够，使用配对置换检验或精确符号检验；若任务量太小，不以单一 p 值替代门槛，而报告全部配对结果。

若未超过基线，即使最终档位符合研究者预期，也只能说明评审者能答，不能说明尺子有效。

### 门 3：可靠性与提示稳健性

至少对一部分任务做重复运行或提示扰动，预注册：

- 同一材料的档位完全一致率；
- 相差不超过一档的比例；
- 序数加权一致性指标；
- 提示改写、顺序变化或随机种子变化后的结论稳定性。

建议最低要求：

- 同材料重复运行至少 **80% 完全一致**；
- 至少 **95% 相差不超过一档**；
- 关键降级触发器的触发与否至少 **85% 一致**。

一致性只是一道必要门，不是效度。多个席位一致地依赖同一错误先验，仍然可能完全无效。

### 门 4：外部或前瞻效度

要宣称“这把尺子确实能测出正在弱化的护城河”，必须使用评分时不可见、且不与输入证据循环的留出结果。最优方案是前瞻性：

1. 在时点 T0 封存档位、置信度和降级触发器；
2. 预先定义未来观察窗口；
3. 预先定义与各机制轴对应的独立结果，而非使用同一输入指标；
4. 到期后只运行锁定脚本结算。

若有多个时间切片或多个机制任务，可检验：较低档位或已触发降级的切片，是否在后续独立结果上系统性更弱。可使用预注册的序数相关、配对方向命中率或事件触发准确率。门槛必须在 T0 前固定。

只有门 0–4 均通过，才可以谨慎宣称存在初步外部效度。若只通过门 0–3，应表述为“该尺子在受控材料上具有可重复的内部构念敏感性和相对基线的增量”，不能缩写成“尺子已被验证”。

## 二、一个可直接执行的结算表

建议最终报告固定输出以下数字，不允许只给叙述性印象：

| 指标 | 结算内容 |
|---|---|
| 身份识别率 | 各席位猜中率及识别置信度分布 |
| 先验锁定率 | 看材料前已有明确档位的比例 |
| 机制方向命中率 | 正确、平局、反向各占比 |
| 重大干预幅度 | 档位变化中位数及分布 |
| 安慰剂误动率 | 无关变化导致档位或置信度显著变化的比例 |
| 缺失响应率 | 转为低置信、收缩或无法评级的比例 |
| 证据落地率 | 关键结论有合规证据 ID 的比例 |
| 外部事实污染率 | 闭卷答案中出现未授权事实的比例 |
| 尺子增量分 | 相对无尺子基线的配对净提升 |
| 席间一致性 | 完全一致、±1 档、一致性系数 |
| 提示稳健性 | 提示或顺序变化后的稳定比例 |
| 协议违规数 | 按严重程度分层统计 |
| 前瞻留出表现 | 仅在留出窗口到期后结算 |

## 三、什么结果绝不能被称为成功

以下任一情形出现时，不能以“最终档位答对”宣布有效：

- 尺子臂不优于无尺子基线；
- 机制相关干预不动，但身份一出现就给出固定结论；
- 安慰剂变化经常引起档位改变；
- 关键证据被删除后仍维持高置信；
- 大量结论没有包内证据支持；
- 多席一致性仅来自同一模型家族；
- 所谓正确答案由研究者主观指定，或由尺子本身循环定义；
- 使用历史案例时评审者已知后续结局，却没有任何前瞻留出；
- 只展示一个“被正确判低”的案例，没有配对干预、基线和失败统计。

# (d) 对照设计

## 一、“应当被判低的真实案例”还能否成立？

它可以作为**弱阳性对照或演示案例**存在，但不能承担确认性验证的核心功能。

原因是：一旦案例可被识别，评审者可能早已知道其被广泛视为弱化、受压或失败。此时“判低”同时符合两种解释：

1. 尺子成功读取了材料中的弱化机制；
2. 评审者识别身份后复述既有结论，再用尺子语言包装。

仅看最终低档无法区分这两种解释。因此，这种真实低档对照最多能检出非常粗糙的失败，例如尺子连一个明显弱案例都无法表达；它不能证明尺子具有独立识别力。

## 二、可替代“低档案例”的装置

### 1. 同身份的退化双生对

以同一身份指纹为底座，构造 A、B 两个版本，只改变一组预注册的弱化机制。评分席不知道哪一项是实验干预，也不知道研究者期待方向。核心结算不是“B 是否绝对判低”，而是“B 是否稳定低于 A，且理由落在被改变的轴上”。

这一装置把身份先验变成常量，能更直接检验尺子的边际响应。

### 2. 多级退化阶梯

构造基础版、轻度弱化版、重度弱化版和证据不足版。预注册期望关系：

- 基础版 ≥ 轻度弱化版 ≥ 重度弱化版；
- 证据不足版未必更低，但应降低置信度或转为无法评级。

这比单一低档对照更有信息量，因为它同时检验单调性、阈值和缺失处理。

### 3. 机制微型锚点

使用虚构或复合的小案例，只放入一两个清楚的机制原语，隐藏评分键。其作用是验证评审者是否理解并一致执行条款。它不验证现实外部效度，但能分离“尺子执行失败”与“现实材料太复杂”。

### 4. 时间切片内对照

在身份固定的情况下比较同一对象不同时点的材料，并只允许使用各时点可得信息。若弱化信号逐步出现，尺子应先在相应轴、置信度或降级触发器上变化，再决定是否跨档。

历史时间切片仍受后见偏差污染，因此最好与前瞻留出结合，而不能单独作为最终证明。

### 5. 未来触发器对照

不要求今天指定一个“必然低”的对象，而是预注册：哪些未来信号出现时必须降级、哪些信号不应引发降级。到未来窗口后机械结算。

这承担了原低档对照最重要的功能——证明尺子能够在弱化发生时响应——同时避免由研究者事先给某个真实案例贴低档标签。

### 6. 竞争方法对照

将完整尺子与无尺子自由判断、通用商业清单、删轴版尺子或随机化的非关键清单比较。若完整尺子在方向敏感性、安慰剂稳定性、证据落地和前瞻结果上没有增量，则“判低成功”应归因于一般判断能力，而不是尺子。

## 三、推荐组合

最推荐的阳性控制不是一个“大家都知道应当低”的真实案例，而是：

- **同身份退化双生对**，承担机制方向检验；
- **安慰剂双生对**，承担特异性检验；
- **证据不足版本**，承担无法评级与置信度检验；
- **未来留出触发器**，承担真正的外部结算。

四者合起来，才比较接近原本“低档对照”想完成的功能。

# (e) 反向质疑

## 一、问题提法中确有几个根本缺陷

### 1. 把“盲性”误当作效度的必要条件

实验不一定需要对标的身份盲，但需要对干预、评分键和未来结局有足够的隔离。身份盲不可得，不等于所有实验都不可做；它意味着必须停止把匿名化当作主要识别策略。

### 2. 把一个潜在构念当成有现成标准答案

“护城河牢固度”不是可直接观察的物理量。若没有独立定义的结果、机制预期或外部准则，就不存在天然的“正确档位”。因此，实验首先要验证的是构念反应、区分效度和增量，而不是把一个主观档位当作金标准。

### 3. 把“当前强弱”和“正在弱化”混为同一输出

一个对象可以当前仍强，但边际趋势在弱化；也可以当前弱，却没有进一步恶化。尺子若只有单一序数档位，需要明确：趋势是档位的一部分、独立维度，还是降级触发器。否则“应当被判低”本身就可能是错误测试目标。

### 4. 把同模型家族的多席当作独立专家

同源模型能够提供重复运行和提示稳健性信息，但不能自然提供独立先验。若所有席位共享训练数据与推理偏好，多席一致不应被解释为多位独立评审共同验证。

### 5. 试图用单一著名案例验证整把尺子

单一大型平台案例只能覆盖部分机制轴，且极易受身份知识、历史结局和舆论共识影响。即使所有控制都做得很好，也只能说明尺子在该材料族中的局部表现，不能支持跨行业、跨周期、跨法域的普遍有效性。

### 6. 将“评审者答对”与“尺子有效”混为一谈

正确结论可能来自先验、常识、材料暗示、后见之明或研究者期望。验证对象必须是尺子的增量贡献和受控响应，而不是答案本身。

## 二、这类实验还值不值得跑？

**作为确认性、一次性验证，不值得。作为可证伪的测量审计，值得。**

它适合回答：

- 尺子条款能否被一致执行；
- 对机制相关变化是否敏感；
- 对无关变化是否稳定；
- 证据不足时是否会合理降置信或拒绝评级；
- 相比一般判断，是否提供可测的增量；
- 哪些轴最易被身份先验或材料结构劫持。

它不适合单独回答：

- 某一个真实案例的“正确档位”到底是什么；
- 尺子已在现实世界得到普遍验证；
- 多个同源模型一致就等于独立专家共识；
- 历史著名弱化案例被判低就等于具备预测能力。

## 三、若要真正检验尺子，应采用组合证据

最合理的验证组合是：

1. **受控反事实与安慰剂实验**：验证内部构念敏感性和特异性；
2. **无尺子基线比较**：验证增量价值；
3. **机制锚点与缺失测试**：验证规则执行和“无法评级”机制；
4. **多时间切片或多类型案例**：检验适用边界，避免单案例过拟合；
5. **前瞻性留出**：检验尚未发生的结果，减少后见偏差；
6. **异源评审或异源方法**：在条件允许时引入不同模型家族、人类领域专家、规则引擎或定量代理，进行方法三角验证。

## 四、最终判断

真盲不可得并不使实验完全无意义，但它改变了能够提出的科学主张。

合理主张是：

> 在身份可识别的条件下，经过预注册、干预盲、证据溯源、安慰剂、缺失测试、基线比较和前瞻留出后，这把尺子是否表现出可重复的机制敏感性、特异性和增量价值。

不合理主张是：

> 某个可识别的大型案例被若干同源评审判到了研究者预期的档位，因此这把尺子已经被证明有效。

因此，建议把本项目正式命名为**“非盲条件下的测量工具压力测试与增量效度审计”**，而不是“盲测验证”。前者可以通过严格控制获得可解释结果；后者在当前约束下容易制造超出证据边界的结论。
